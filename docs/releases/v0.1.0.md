## Жизнь 0.1.0 — каркас и первая рабочая версия

**Что можно делать**

- Записывать текстом в поле на экране «Сегодня». Несколько дел — с новой строки или через «;».
- Приложение само понимает: «завтра», «в пятницу», «25 октября», «30.10», «через 3 дня», «в 15:00», «с 18 до 20»,
  повторы («каждый день», «по понедельникам и средам», «каждые 3 дня», «каждое 10 число»), важность 🔴🟡🟢 и сферу.
- «Практикум по ОРП» становится ДЗ к ближайшей паре по расписанию, срок — накануне.
- «обед 7,5», «жим 60 на 10», «вес 72,5» — в журнал; «идея: …», «привычка: …», «цель: …».
- Сегодня: прогресс дня, пары с отметкой посещения, дела, привычки, лента последних записей.
- Дела списком по срокам, поиск, фильтр по сферам, свайпы «сделано» и «на завтра», «Отменить» после любого действия.
- Учёба: расписание группы 3102 с сайта ФКМ, изменения, зачёты с обратным отсчётом.
- Привычки сеткой ✓ / – / ✗, процент и серия.
- Напоминания: план в 6:30, итог в 21:30, дела со временем. На телефоне с 8:00 до 16:00 тишина, в 16:00 — сводка.
- Синхронизация телефона и ноутбука через вашего личного Telegram-бота («Ещё → Синхронизация»).
- Вход по PIN («Ещё → Вход по PIN»).
- Сферы 💰 Финансы и 👤 Личное, напоминание о недельном обзоре в воскресенье в 20:00.
- Windows: трей, автозапуск, `Ctrl + Alt + N` — мини-окно записи, перетаскивание файлов, вставка скриншота.
- Android: «Поделиться → Жизнь», кнопка «Записать» в шторке, настройка телефона Tecno.
- Новые версии приложение находит само.
