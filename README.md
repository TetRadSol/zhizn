# Жизнь

Одно приложение для Android и Windows 11 вместо Ритма, Excel-трекера и Железного цикла.
Вы пишете как удобно — приложение раскладывает записи по делам, событиям, привычкам,
заметкам и журналу. Позже к разбору подключится помощник Джарвис (Claude Code на ноутбуке).

## Как поставить

- **Телефон:** [скачать Zhizn.apk](https://github.com/TetRadSol/zhizn/releases/latest/download/Zhizn.apk) → открыть файл → «Установить».
  При первом запуске приложение проведёт по настройкам телефона Tecno (уведомления, батарея, автозапуск).
- **Ноутбук:** [скачать Zhizn-Setup.exe](https://github.com/TetRadSol/zhizn/releases/latest/download/Zhizn-Setup.exe) и запустить. Права администратора не нужны.
  Приложение стартует вместе с Windows в трее; `Ctrl + Alt + N` — быстрая запись из любой программы.

Новые версии приложение находит само и предлагает обновиться.

**Синхронизация.** У каждого устройства своя полная база, приложение работает без интернета.
Каждое изменение — это запись «поле X записи Y стало Z, время, устройство». Ноутбук слушает
домашнюю сеть (порт 47821, поиск — 47822). Телефон один раз связывается с ним по шестизначному
коду и получает общий ключ; дальше, когда оба в одной сети Wi-Fi, телефон отправляет свои новые
изменения и забирает новые с ноутбука. Всё передаваемое зашифровано. Если одно поле поменяли
на двух устройствах, побеждает поздняя правка, старая остаётся в истории.

**Джарвис.** На ноутбуке по расписанию (и по кнопке) приложение пишет `input.json` с новыми
записями, делами, расписанием и профилем и запускает `claude -p` (Claude Code по подписке) с
инструкцией из `assets/jarvis_prompt.md`. Claude может только читать файлы. Ответ — JSON с изменениями,
вопросами и итогом дня; приложение проверяет каждое поле, отбрасывает лишнее, ничего не удаляет и
помечает, что изменил Джарвис. Если лимит подписки исчерпан или ноутбук выключен — работают правила.

**Коннектор.** Приложение отвечает на MCP-запросы по `http://127.0.0.1:47821/mcp` (только с этого
компьютера). Кнопка «Подключить к Claude Desktop» кладёт мост `zhizn-mcp.ps1` и прописывает его в
`%APPDATA%\Claude\claude_desktop_config.json`.

**Сборка.** Код собирает GitHub Actions (`.github/workflows/release.yml`): на тег `v1.2.3`
появляются APK и установщик Windows в Releases. На ноутбук ничего, кроме самого приложения, ставить не нужно.

Ключ подписи APK лежит в репозитории зашифрованным (`android/app/upload.jks.enc`), пароль к нему —
секрет репозитория `ANDROID_KEY_PASSWORD`. Без него каждая сборка подписана разным ключом и не встанет поверх старой.

**Проверка.** `flutter test` — автотесты разбора дат, повторов, расписания, синхронизации и напоминаний;
идут на каждую сборку.

Что сделано в каждой версии — в `docs/releases/`.
