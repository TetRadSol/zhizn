# Жизнь

Одно приложение для Android и Windows 11 вместо Ритма, Excel-трекера и Железного цикла.
Вы пишете как удобно — приложение раскладывает записи по делам, событиям, привычкам,
заметкам и журналу. Позже к разбору подключится помощник Джарвис (Claude Code на ноутбуке).

## Как поставить

- **Телефон:** раздел [Releases](../../releases) → скачать `Zhizn-x.y.z.apk` → открыть файл → «Установить».
  При первом запуске приложение проведёт по настройкам телефона Tecno (уведомления, батарея, автозапуск).
- **Ноутбук:** там же скачать `Zhizn-Setup-x.y.z.exe` и запустить. Права администратора не нужны.
  Приложение стартует вместе с Windows в трее; `Ctrl + Alt + N` — быстрая запись из любой программы.

Новые версии приложение находит само и предлагает обновиться.

## Как устроено

| Часть | Где в коде |
|---|---|
| База на устройстве (SQLite) и журнал изменений | `lib/data/store.dart` |
| Виды записей: задача, привычка, запись, заметка | `lib/data/models.dart` |
| Разбор записей правилами: даты, время, повторы, сферы, ДЗ к паре | `lib/logic/parser.dart` |
| Расписание ФКМ: загрузка и разбор строки пары | `lib/logic/schedule.dart` |
| Повторы задач | `lib/logic/recurrence.dart` |
| Синхронизация через закрытый репозиторий GitHub | `lib/services/sync.dart` |
| Напоминания, тишина 8:00–16:00, сводка | `lib/services/reminders.dart` |
| Трей, горячая клавиша, мини-окно (Windows) | `lib/services/desktop.dart` |
| Проверка обновлений | `lib/services/updates.dart` |
| Экраны | `lib/ui/screens/` |

**Синхронизация.** У каждого устройства своя полная база, приложение работает без интернета.
Каждое изменение — это запись «поле X записи Y стало Z, время, устройство». Устройство
выкладывает свои новые изменения отдельным файлом в `log/<устройство>/` закрытого репозитория
с данными и забирает чужие файлы. Файлы никогда не переписываются, поэтому конфликтов нет;
если одно поле поменяли на двух устройствах, побеждает поздняя правка, старая остаётся в истории.

**Сборка.** Код собирает GitHub Actions (`.github/workflows/release.yml`): на тег `v1.2.3`
появляются APK и установщик Windows в Releases. На ноутбук ничего, кроме самого приложения, ставить не нужно.

Ключ подписи APK хранится в секретах репозитория: `ANDROID_KEYSTORE_BASE64` и
`ANDROID_KEY_PASSWORD`. Без него каждая сборка подписана разным ключом и не встанет поверх старой.

**Проверка.** `flutter test` — автотесты разбора дат, повторов, расписания, синхронизации и напоминаний;
идут на каждую сборку.

Что сделано в каждой версии — в `docs/releases/`.
